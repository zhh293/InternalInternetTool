# 发布记录

## 0.4.1

- 推送main即可触发构建和Actions产物上传；版本标签构建生成Release草稿。
- 提供Linux amd64/arm64、Windows amd64附带Java运行时的分发包，以及通用Java包和SHA-256文件。
- 修复跨事件循环的DATA发送顺序：先入队的数据不能被当前事件循环中的后续写入超越，CLOSE也排在待发送DATA之后。回归用例`MuxOrderingSmoke`在旧实现中稳定观察到`[2,1]`，修复后要求`[1,2]`。
- 1MiB完整性检查改用固定种子的伪随机内容，失败时显示首个不一致位置，减少周期性内容掩盖重排的可能。
- Windows英文系统上的不可表示中文路径是JDK启动器限制，文档建议使用英文目录。发布检查验证空格路径，并在系统字符集可表示时验证中文路径。

`v0.4.0`首次远程发布构建未通过，没有发布可下载的Release：Linux amd64完整性检查失败，Windows英文系统中文路径启动失败。该失败记录保留；0.4.1包含上述修正，不移动旧标签，不跳过数据完整性检查。
